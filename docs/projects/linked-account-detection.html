Linked-account detection

Every account that reaches the upgrade stage is checked automatically for links to other accounts.

My role
Designed the detection
Where
City Traders Imperium
Tools
Excel, then Python and SQL

Problem

Before an account is upgraded, it has to be checked for links to other accounts that could point to one person trading under several identities.

My part

I designed the linked-account detection, starting as an Excel model, and worked with a colleague on flagging suspicious connections. Both checks now run inside my automated account-review tool.

Result

3 minutes

Every account that reaches the upgrade stage is checked automatically. A full account review, trading rules and linked accounts together, takes about 3 minutes on average.

This is work for my employer, so the details here are kept general. I'm happy to go into more depth in an interview.
