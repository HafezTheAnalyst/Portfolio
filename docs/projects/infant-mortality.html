What drives infant mortality in high-GDP countries

A Tableau data story covering the three highest-GDP countries in each region from 2000 to 2012.

Type
Personal project
Period
2000 to 2012
Tools
Tableau

The question

In the richest countries of each region, which factors move with infant mortality: birth rate, health spending per person, health spending as a share of GDP, population or GDP itself?

What I did

  • Built an interactive Tableau dashboard on the health measures
  • Turned it into a guided story, so a reader follows the argument page by page
  • Set up filters for healthcare, public health and general readers
